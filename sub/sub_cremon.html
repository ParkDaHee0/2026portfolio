MS파크골프 웹사이트

파크골프 웹사이트 리뉴얼 프로젝트로, 블루 컬러 기반의 청량한 무드와 스윙의 시각적으로 표현했습니다. 직관적인 구조와 인터랙션 설계를 통해 사용 경험과 몰입도를 동시에 개선했습니다.

  • Here-Brand-Location

    파크골프의 경쾌하고 시원한 스윙 이미지를 전달하기 위해, 전체적으로 블루 계열을 메인 컬러로 설정하고 시각적인 청량감을 강조했습니다. 메인 비주얼은 라운드형 요소와 부드러운 곡선 레이아웃을 활용하여 기존 골프의 딱딱한 이미지를 벗어나 친근하고 접근성 있는 스포츠 브랜드 이미지를 표현했습니다. 콘텐츠 구성은 사용자의 시선 흐름을 고려해 히어로 섹션 → 브랜드 소개 → 매장 안내 → 시뮬레이션 기능 → 제품 → 공지 → 문의 순으로 자연스럽게 이어지도록 설계했습니다. 특히, 카드형 UI와 라운드 디자인을 적극 활용해 통일감 있는 비주얼 구축 시뮬레이션 섹션은 컬러 블록과 이미지 대비를 통해 기능별 구분을 명확하게 강조 제품 영역은 그리드 기반으로 구성하여 가독성과 정보 전달력을 강화 전체적으로 직관적인 구조와 부드러운 인터랙션을 통해 사용자 경험(UX)을 개선하는 데 중점을 두었습니다.
